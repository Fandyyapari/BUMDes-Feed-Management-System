# Sahabat Padi 🌾

Sistem berbasis AI untuk membantu identifikasi penyakit/hama tanaman padi melalui foto.

## Teknologi

- React + Vite
- Tailwind CSS
- FastAPI
- Python
- TensorFlow/Keras
- Supabase

## Struktur Project

- `frontend/` → tampilan web
- `backend/` → API
- `ai/` → model dan eksperimen AI
- `docs/` → dokumentasi
